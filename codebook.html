Interactive Codebook

This interactive codebook provides detailed information on all 404 variables in the cleaned SSI-2012 dataset. You can search, filter, and sort variables by name, description, data type, or value categories.

Use the search bar on the top-right to find specific terms (e.g., searching “jazz”, “income”, “female”, or “concur”), or filter columns directly.

Column Descriptions in the Metadata

The table above contains the following columns for each variable:

  1. Variable Name: The short name of the column in the dataset (e.g., classicaltaste, female).
  2. Description / Label: A plain-English explanation of what the variable represents.
  3. Data Type: Whether the variable is Categorical (Labelled), Numeric, Character (Text), or a Binary Indicator (0/1).
  4. Value Codes / Categories: For categorical and binary variables, this column displays the numeric codes and their corresponding text meanings (e.g., 1 = like; 2 = dislike). For numeric columns, it displays the valid range.
  5. Valid N: The number of non-missing observations (out of 2,276 total).
  6. Missing N: The number of missing (NA) observations.
  7. Missing %: The percentage of respondents with missing values for that variable.
