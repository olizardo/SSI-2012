# SSI-2012 project memory

## What this is
Cultural tastes dataset from Survey Sample International (SSI), collected by Omar Lizardo and Sara Skiles in 2012. Documentation is a Quarto website in `website/`, rendered to `docs/`. Dataset license: CC BY 4.0. The authors own the data.

## Record count and file layout
- Released data: 2,275 records, 404 variables. 2,258 have `finished == 1` ("complete record"); 17 have `finished == 0` ("some missing data"). Partial records are kept.
- `data/raw/SSI2012.dta` has 2,276 rows. The extra row has no `id` and carries only derived variables. `scripts/clean_data.R` drops rows with missing `id`.
- Cleaned outputs (`data/clean/`): `ssi2012_cleaned.{csv,rds,dta,sav}`, `ssi2012_cleaned_coded.csv`, and `ssi2012_codebook_metadata.{csv,rds}`, generated by `scripts/generate_codebook.R`. Run both scripts from the project root.
- `ssi2012_cleaned_coded_with_scores.csv` and `ssi2012_cleaned_coded_with_true_scores.csv` contain derived columns that no script in this repo generates (`assigned_class`, `subgroup_competence`, `true_overall_competence`, `low_checker_consistency`). Do not delete or regenerate them. Their provenance is undocumented.

## Sampling documentation
- The authoritative sampling description is Chapter 2 (Sections 2.1 and 2.3) of Skiles (2014), *Aesthetic Taste Expression and Symbolic Boundary Work*. DOI 10.7274/z890rr19n23. ProQuest publication number 3731603.
- The dissertation PDF is All Rights Reserved. It lives at `docs/SkilesDuTroitS072014D.pdf`, is listed in `.gitignore`, and must not be committed or linked from the site. Cite it by DOI.
- Dissertation condition and demographic counts (529 control, 1,746 experimental, 1,184 female) match all 2,275 records, including partials. They do not match the complete-only subset. So the released file is the analytic sample.
- The dissertation reports 16 early stoppers as excluded. IDs 1 to 16 are present in the file as partial records. The original Qualtrics export is no longer available, so this cannot be resolved. The site notes this discrepancy in the sample section.

## Remote, branches, and publishing
- Remote `origin` is `https://github.com/olizardo/SSI-2012`. The owner is `olizardo`, not `omarlizardo`.
- Default branch is `master`. Do not use `main`; it is an unrelated older history.
- The live site is served by GitHub Pages from the `gh-pages` branch, not from `docs/` on `master`. Keep this setting. Publish by creating a commit on top of `origin/gh-pages` whose tree equals `docs/` from `master`, then pushing it as a fast-forward. Never force-push `gh-pages`.
- The live site is https://olizardo.github.io/SSI-2012/. `website/_quarto.yml` sets `site-url` so `robots.txt` and `sitemap.xml` are generated. Removing that setting drops both files from the live site.
- Download links in `website/download.qmd` point to `raw.githubusercontent.com/olizardo/SSI-2012/master/data/clean/`. Raw URLs are CDN-cached for up to about 5 minutes after a push.
- Pushes to `master` and `gh-pages` need explicit approval from the user each time.

## Rendering and known quirks
- Render with `cd website && quarto render`. Quarto warns that it refuses to remove `docs/explore_files` and `docs/site_libs`, so stale hashed CSS and JS files can remain. Check `git status` after rendering.
- The explore page prose hard-codes counts (1,247 of 2,264 like classical; 79 unfamiliar; taste1 modal codes 2 and 3). Update the prose if the data changes.
- `taste1` codes: 1 = "I like it very much" through 7 = "I dislike it very much"; 98 = "I can't see the image".
